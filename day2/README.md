# Day 2 (Tue): TypeScript fundamentals

## Learn
- Variables & types: `string`, `number`, `boolean`, arrays, objects
- `if / else`, `for`, `while`, functions, return values
- Sources: javascript.info Part 1 (ch. 2), TypeScript Handbook "The Basics" and "Everyday Types"

## Task
Open `src/` and finish all 10 exercises. Each file explains what the function must do.

```bash
npm install
npm test          # see which exercises pass / fail
```

## Rules
- **1 commit per exercise**, e.g. `day2: ex03 fizzbuzz`.
- Do not edit `tests/`.
- Use fake IC numbers only in ex08.

## Done when
- `npm test` shows all tests passing.
- You can explain any exercise line by line **and change a rule live** (e.g. "make A start at 85").
