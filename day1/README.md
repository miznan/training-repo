# Day 1 (Mon): Setup & first program

## Learn
- Terminal: `pwd`, `ls` (or `dir`), `cd`, `mkdir`
- Git: `clone`, `status`, `add`, `commit`, `push`, `log`
- What `npm install` and `npm start` do

## Task
1. Finish `hello.ts` (follow the TODOs).
2. Run it: `npm install` then `npm start`.
3. Do the exercises in `git-practice.md`.
4. Push to your branch.

## Done when
- `npm start` prints your name, your course and your 3 goals.
- Your branch has **at least 3 commits** with meaningful messages.
- You can answer: *What is a commit? What happens when you run `npm start`?*
